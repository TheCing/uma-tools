## Quick Tips

1. **Speed is king** - but you need enough stamina to finish
2. **Match aptitudes** - S/A aptitude makes a big difference
3. **Check survival rate** - if it's low, add more stamina or recovery skills
4. **Consider running style** - Betweeners are most stamina-efficient
5. **Mood matters** - Great mood gives +4% to all stats

## Using the Simulator

1. Set your horse's stats, aptitudes, and skills
2. Choose a race course and conditions
3. Click "Run" or "Compare" to simulate
4. Check results for time, position gains, and survival rate
